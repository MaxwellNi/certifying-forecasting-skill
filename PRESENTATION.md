# Explaining the result

Start with a demand forecast that repeats last week's sales. Its accuracy can be
useful. The research question is what a proposed forecast comparison measures,
and whether sharing the observations used for ranks changes that quantity.

1. Define the comparison. A fitted forecast-minus-baseline rank contrast is
   different from removing everything the baseline can reveal. If a baseline U
   is uniform on {-1, 0, 1} and both forecast and outcome equal U squared, the
   fitted rank contrast is 7/54 even though full adjustment for U leaves zero.
2. Show the source diagram. For fixed maps, reference law and row sums, the
   overlap matrix C D-transpose determines preservation for every map and law.
   Zero in every entry is the universal condition. A nonzero matrix can still
   have zero interaction for a particular law.
3. Explain the certificate. Independent training fixes the design. Independent
   whole trajectories supply evaluation and correction blocks. Subtract the
   observable interaction and both uncertainty radii from the score.
4. Show the eight-model comparison. Removing unused reference roles and
   reallocating the same draw budget narrows the shared hybrid radius by 23%
   for the illustrated boosting model. It does not change the shared gate.
   Complete U is the stronger direct estimator when all draws can be reused.
5. State the decision evidence. Every candidate and subsequent loss is shown.
   A positive archive rank target does not by itself establish future loss
   improvement. The shared gate adds no gain over choosing persistence here.
