# Dataset attribution and license

Torgo, L. and Moniz, N. (2018). *News Popularity in Multiple Social Media
Platforms*. UCI Machine Learning Repository. [DOI: 10.24432/C5H029](https://doi.org/10.24432/C5H029).

The [UCI dataset page](https://archive.ics.uci.edu/dataset/432/news+popularity+in+multiple+social+media+platforms)
licenses the dataset under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
The original ZIP is included unchanged. Only the Facebook/economy and news
metadata members are used. The features, label splits and forecasts in the
results directory are derived artifacts; their transformations are documented
in confirmation/config.json and the executable loader.

Source ZIP SHA-256: `5b8a7a10c8942a611da33d0fd4df7cb100f9f1b47d49a73fd13b142624f66f81`.
The provider's timestamps support the nominal time grid but do not independently
prove each feature was historically available at its assumed deadline.
