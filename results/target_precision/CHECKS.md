# Scope of the executable checks

The portable code has executed these checks successfully:

- Nine source-loader, staging and numerical-summary tests.
- Four exact tuple cases, 200 randomized full-U cases and 2,341 deletion checks;
  exact finite-support projection checks retain degenerate higher-order terms.
- Six stratified identities and 7,200 null draws across 18 fixed cells.
- Forty high-precision profiled optimization comparisons, 147 heterogeneous-null
  count states and deliberately truncated optimizer checks.
- Forty-two finite-support betting rounding checks.
- One hundred twenty-five loss endpoint cases and a 256-path dependent tree.
- Binary support, row/count equivalence and all 256 ordered four-row blocks.
- Ninety-six gate-composition formulas and three literal BY families.
- All 8,000 paired binary repetitions: rejection, lower-bound and p-value arrays
  reproduce exactly. The descriptive four-row betting centers have 1,683 tiny
  addition-order differences, at most 3.47e-18. All inference decisions agree.
  Method timings are platform dependent and excluded from equality claims.

The formula-check JSON reports sit beside their check scripts. These finite
checks do not validate IID assumptions on temporal source rows, exact external
metadata, historical feature availability, general statistical optimality or
unseen-data custody. Recorded experiments and repeated code execution are
different from an external third-party reproduction. The news runner and
comparison utility support a separate complete source-to-prediction retraining
check. A second run cannot add another independent task to the evidence count.
