# Reference certificate figures

These reader copies use the same fonts and coordinates as the paper. Figure 1
shows both category validation/evaluation and whole-trajectory reference roles.
The two branches preserve different declared targets. Numerical figures retain
every ablation budget and all 72 validation settings; intervals are pointwise,
and bias slack is not a final decision threshold.

Use the [paper figure instructions](../paper_figures/README.md) to rebuild all
four figures. SVG glyphs are outlined from the corresponding PDFs.
`make_validation_reader.py` supplies an alternative layout of the same numerical
data, while the final IEEEtran-template layout is generated by
`make_ieee_figures.py` and `make_reference_design.py`.

The complete multi-panel factorial figure and all 41 model comparisons remain
in the accompanying technical details and released files.
