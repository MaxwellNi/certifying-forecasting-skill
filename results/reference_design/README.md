# Reference design and cross-time interaction

The exact enumeration covers all 512 arrays of three independent binary
entities at three times. The current forecast copies the previous outcome.
Complement-fold fitting of within-time empirical midranks has expected score
−3/32, versus −1/16 with population midranks. The contemporaneous reference
term is zero; shared peers across time change the feedback variance.

Run `python results/reference_design/check_temporal_rank.py` from the package
root. It prints exact rational moments and leaves saved evidence unchanged.
The main paper contains the full calculation. The companion also gives the
weighted-overlap identity, its target-shift terms and heterogeneous-peer
limits. These are design-specific covariance calculations, not a guarantee
for arbitrary dependent rank panels.
